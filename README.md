# ga4-gtm-config-mcp

Custom MCP server for safe GA4 and Google Tag Manager configuration automation.

It consumes an approved `*.mcp-execution.yaml` desired-state spec generated by `google-analytics-implementation-planner`, validates it, compares it against current GA4/GTM state, applies approved changes to a new GTM workspace, creates preview versions, and blocks publishing unless explicitly approved.

This is an execution layer, not an analytics planner. It does not invent events, tracking strategy, custom dimensions, or GTM architecture.

## Status

Early scaffolding. No stack, dependencies, or runtime entrypoint yet — see [AGENTS.md](AGENTS.md) section 10 for current project context.
